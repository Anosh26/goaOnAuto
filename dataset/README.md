# Dataset Directory

This directory stores ground-truth documents and training samples used to evaluate and benchmark OCR and classification accuracy.

## Folder Structure
- `samples/`: Anonymized / mock test samples safe for version control.
- `raw/`: Real-world documents and pre-existing customer scans (ignored by Git for privacy/PII protection).

## Expected Document Categories
- `aadhaar/`: Aadhaar Cards (Front / Back / Merged)
- `pan/`: PAN Cards
- `voter_id/`: Voter ID Cards
- `residence_cert/`: Residence Certificates (15-Year / Child / Self)
- `caste_cert/`: Caste / OBC Certificates
- `birth_cert/`: Birth Certificates (Form 5)
- `marriage_cert/`: Marriage Certificates (Form 16)
- `bonafide_cert/`: School / College Bonafide Certificates
- `marksheet/`: SSC / HSSC / College Marksheets
- `electricity_bill/`: Electricity Bills
- `house_tax/`: House Tax Receipts
- `ration_card/`: Ration Cards
- `passport_photo/`: Passport Photos
- `signature/`: Scanned Signature Crops
